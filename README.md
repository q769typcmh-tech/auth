# Vasper Shield

Independent script licensing **demo website** (white + yellow).

- Product landing page  
- Dashboard overview  
- Projects & scripts  
- License keys (generate / revoke / expiry)  
- Loader template + in-browser deliver test  

Data is stored in **your browser** (`localStorage`). There is **no real API server** in this demo yet.

Not affiliated with Luarmor or any other brand.

## Local
