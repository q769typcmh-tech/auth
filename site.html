How it works

Independent design — not affiliated with other brands.

Architecture

Dashboard manages projects, scripts, and keys (this website).
API (future Node server) validates licenses and returns script bodies.
Loader is a small public Lua file users run; it calls your API first.
This demo stores data in localStorage so you can try the workflow without a server.

1. Project

Gets a public ID the loader embeds.

2. Script

Lua source saved as the current version.

3. License

Random key + optional expiry + revoke.

4. Loader

Sends project id + key → receives script if allowed.

5. Update

Change script in dashboard; loader URL stays the same.

6. Revoke

Key stops working on next deliver check.
